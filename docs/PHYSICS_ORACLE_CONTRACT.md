# 论文二：物理约束的输入与拒绝条件

现在准备契约；12 月集中实现和实验。暂未计算有效参数区间。

Oracle 读取已审查的质量/载荷/重心、几何、驱动能力、地面/坡度、延迟、按工况实测的制动减速度下界及其适用范围。输入必须有单位、来源、误差和有效工况。

任何关键输入未知、单位不明、工况越界或证据不一致，都返回 insufficient_evidence，而非自动补默认值或输出“安全”。设计模板与实车测量是不同证据层级。

输出应包含候选参数、每条约束的余量/违背理由、适用工况、输入摘要和计算版本。Agent 可以在约束内提出参数，不能改物理判据、安全界限或测量结果。最终 admissible 表示满足模型及输入假设，不能单独称为整车安全认证。

共用 harness 与独立 evaluator；保留规则/人工调参与 Agent 方法的统一预算、失败和边界样例。正式对照设计沿用冻结研究计划，不能把未知制动数据补成漂亮的仿真图。
