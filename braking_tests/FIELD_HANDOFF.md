# 交给现场负责人的准备单

状态：NOT_APPROVED / NOT_RUN。本文不授权测试，具体操作以审批后的 protocol.md 为准。Codex 不控制车辆。

请先提供已有记录：实车 firmware build/configuration 与 Jetson commit/launch 参数；空载质量、代表性载荷及重心；轮径/轮距的校准结果；驱动型号及制动设置；独立急停/隔离场地的有效检查记录。

审批必须明确负责人和操作者、测试日期/场地、允许的速度与重复次数、载荷/地面/坡度/轮胎条件、隔离距离、停止条件、应急角色和测量仪器校准。未完成审批前，不填写“已批准”。

采集文件至少含 run_id、工况、实际速度与位置的外部测量、命令/触发/停止时间、传感器采样率与误差、原始数据摘要。编码器停止不能单独证明车体停稳。软件斜坡值不是实测最保守减速度。

分析时保留每次重复和异常，分工况报告制动距离/减速度及误差。保守下界的计算方法须在分析前确定；不能拿一次峰值或所有工况的简单平均作为 a_min。延迟项单独记录，避免在制动距离公式里遗漏或重复计数。

600/1000 kg 是未来额定载荷的参数模板；不要求本轮给现有车装这些载荷，也不把现有车测量外推成大型平台验证。
